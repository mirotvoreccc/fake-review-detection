# Обнаружение сгенерированных отзывов о товарах

Классификация англоязычных отзывов по тексту. Модель различает исходные отзывы о товарах и отзывы, сгенерированные компьютером. В качестве признаков используются только слова из текста отзыва. Категория товара и оценка в звёздах в модель не подаются.

## Результаты

Логистическая регрессия показала наибольший F1 на валидации. На отложенном тесте из **8 097 отзывов** она получила **F1 0,8583**, **accuracy 0,8587** и **ROC-AUC 0,9308**.

| Модель | F1 на валидации | ROC-AUC на валидации |
| --- | ---: | ---: |
| Multinomial Naive Bayes | 0,8471 | 0,9264 |
| Gradient Boosting | 0,7650 | 0,8648 |
| Логистическая регрессия | **0,8576** | **0,9348** |

На тесте модель нашла 3 464 из 4 050 сгенерированных отзывов. Из 4 047 исходных отзывов 558 она ошибочно отнесла к сгенерированным. Полные метрики, размеры выборок и матрица ошибок доступны в [results.json](results.json).

## Данные и методика

В используемой версии Fake Reviews Dataset 40 526 записей. Метка `0` означает исходный отзыв, `1` — сгенерированный. Версия датасета зафиксирована в коде. Файлы с отзывами в репозиторий не входят. [Карточка датасета на Hugging Face](https://huggingface.co/datasets/lava5675/Fake-Reviews-Dataset) · [Статья Salminen и соавторов](https://doi.org/10.1016/j.jretconser.2021.102771)

1. Нормализуем регистр и Unicode, выделяем слова и убираем пустые тексты. Для одинаковых текстов сохраняем одну запись. Если метки различаются, исключаем всю группу. В этом прогоне удалены один пустой текст и 44 повтора.
2. Делим 40 481 уникальный отзыв на обучение, валидацию и тест в пропорции 60/20/20. Сохраняем доли классов и фиксируем `seed=42`.
3. Обучаем TF-IDF внутри `Pipeline` только на обучающих текстах. Сравниваем модели по F1 для сгенерированного класса на валидации. Тест оцениваем только для выбранной модели. Для метрик по предсказанным меткам используем порог 0,5.

## Запуск

Проверено на Python 3.14.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/experiment.py --output results.json
```

При первом запуске датасет скачивается с Hugging Face. Для запуска с локальной копией той же версии укажите `--arrow-file /path/to/fake-reviews-dataset-train.arrow`.

## Ограничения

Метрики показывают качество на одном англоязычном корпусе. Близкие по смыслу дубликаты, отзывы на других языках, тексты современных генераторов и написанные людьми фальшивые отзывы отдельно не проверялись. Классификация текста сама по себе не подтверждает подлинность отзыва.
